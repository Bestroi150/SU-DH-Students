## Academic Reading

### Core Humanities Computing Texts

**Data and Databases**
- Flanders, Julia and Fotis Jannidis. *The Shape of Data in the Digital Humanities*. Routledge, 2018.
  - Comprehensive guide to data structures in humanities
  - Covers databases, XML, markup
  - Essential reading for understanding humanities data

- Posner, Miriam. "Humanities Data: A Necessary Contradiction?" [Blog post, 2015]
  - Discusses challenges of applying data science to humanities
  - Explores tensions between humanistic and quantitative approaches

- D'Ignazio, Catherine and Lauren F. Klein. *Data Feminism*. MIT Press, 2020.
  - Critical perspective on data representation
  - Examines power dynamics in data collection
  - Includes humanities applications

### Specific Domain Topics

**Epigraphy and Inscriptions**
- Boardman, John. *The Greeks Overseas*. Thames and Hudson, 1980 (multiple editions).
  - Comprehensive survey of Greek colonization
  - Foundational work for historical geography

- Braund, David. *Scythia and the Black Sea*. Amsterdam, 2005.
  - Focused on Black Sea region
  - Primary sources and archaeological evidence

**Numismatics**
- Crawford, Michael H. *Coinage and Currency*. British Museum Press, 1983.
  - Introduction to ancient coinage systems
  - Includes data on denominations and mints

- Gitler, Haim. "Ancient Coins" in *The Ancient World*. Academic Press, 2012.
  - Digital approaches to numismatic data
  - Database design for coins

**Digital Humanities**
- Kansa, Eric. "Open Context and the Archaeology of the Future." *Journal of Eastern Mediterranean Archaeology and Heritage Studies* 3.1 (2015): 63-77.
  - Open data principles in archaeology
  - Interoperability and reusability

- [Frictionless Data - CSV Standard](https://specs.frictionlessdata.io/csv/)
- Community standard for CSV best practices
- Includes validation tools

**XML and TEI**
- [W3C XML Standards](https://www.w3.org/XML/)
- Official XML documentation and specifications

- [TEI Guidelines](https://www.tei-c.org/)
- Text Encoding Initiative specifications
- Complete guide to TEI markup
- Includes epidoc guidelines for inscriptions

- [TEI by Example](http://www.tei-c.org/release/doc/tei-p5-examples/html/)

## Quick-Start Guides

### Starting with CSV Data

1. Open in spreadsheet (Excel, Google Sheets)
2. Explore structure and contents
3. Check for data quality issues
4. Create data dictionary
5. Export to JSON or XML
6. Use in analysis or visualization

### Converting to GeoJSON

1. Start with CSV containing latitude/longitude
2. Use Python script (see documentation)
3. Validate GeoJSON format
4. Upload to GeoJSON.io or mapping tool
5. Create interactive web map

### Publishing Data on GitHub

1. Create new repository
2. Add README.md with description
3. Add LICENSE file (CC-BY-4.0)
4. Add CITATION.cff for citations
5. Upload data files
6. Add documentation folder
7. Enable GitHub Pages (optional)

### Citing Data

1. Find README in project folder
2. Look for "Citation" section
3. Choose format (APA, MLA, BibTeX)
4. Copy and paste into your work
5. Add URL and access date

## Tips for Effective Learning

✓ **Learn by doing:** Create your own small dataset

✓ **Join communities:** Participate in DH forums
