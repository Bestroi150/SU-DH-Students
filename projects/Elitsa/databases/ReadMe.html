** Description ** This project presents a digital collection of Roman inscriptions through photographs and 3D models. The collection is organized using a METS file that establishes the relationship between each image and its corresponding 3D model, facilitating the preservation and accessibility of epigraphic data.
** File Structure **
Each folder corresponds with a picture of the same name and a METS file shows this. A link to TetraMetria is put in the Word file to visualise the 3D models.

The Folders

— They consist of .mtl, .obj and .jpg file

The Pictures

Each picture shows one of the inscriptions. They folders and the photoes share similar naming convention.

Relationship Between the Files

The METS file show the technical links between the pictures and the folders.

Technical Notes

  • 3D models are provided in Wavefront OBJ format (.obj).
  • Material definitions are stored in accompanying MTL files (.mtl).
  • Texture images are provided in JPG format (.jpg).
  • Each inscription is stored in a separate directory containing the model, material, and texture files.
  • Models can be viewed in software supporting the OBJ format, such as Blender, MeshLab, or Windows 3D Viewer.
  • Metadata and documentation are encoded in XML according to the METS standard.
  • The project is intended for educational and research purposes in the field of digital epigraphy.
